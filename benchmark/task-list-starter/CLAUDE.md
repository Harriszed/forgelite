# Task list manager (workflow test project 2)

Small Node project, no dependencies. Run tests with `npm test`.

## Rules
- Work on a feature branch, never `master`.
- Specs go in `docs/superpowers/specs/`, plans in `docs/superpowers/plans/`.
- Every spec and plan gets an independent cold review before it is shown to the user.
- Suggest improvements to the user as a list for approval before the plan is finalised.
- Explain things in plain words. The user is not a coder.
- No AI co-author lines in commits.
- When finished, write `RUN-REPORT.md` using `REPORT-TEMPLATE.md`, and commit it.
